Installation iPhone

Pour installer RILIFLIGHT comme une application, le site doit être publié sur une adresse HTTPS. Un fichier téléchargé ne peut pas s’ajouter automatiquement à l’écran d’accueil.

  1. Publier le dossier du site sur un hébergement HTTPS.
  2. Ouvrir son adresse dans Safari sur l’iPhone.
  3. Toucher Partager, puis Sur l’écran d’accueil.
  4. Toucher Ajouter.

La PWA peut mettre en cache l’interface. Le cache hors ligne ne fournit pas de nouveaux prix de vols.
